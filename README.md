# بوت التحليل (مرحلة ١ — الأساس)

بوت يحلل ويجمع معلومات فقط — **لا ينفذ أي صفقة أبداً**. أنت من يقرر ويضغط الزر عند بوبيان كابيتال.

## ⚠️ إخلاء مسؤولية
- هذا الكود لأغراض تعليمية/بحثية فقط، وليس توصية استثمارية.
- قائمة الأسهم "الحلال" في `data/halal_watchlist.py` **مثال فقط** — لازم تستبدلها بقائمة رسمية معتمدة (من بوبيان كابيتال أو مؤشر إسلامي معروف). البوت ما يفتي، هو بس يلتزم بالقائمة اللي تعطيه إياها.
- تحقق دائماً بنفسك قبل أي قرار مالي، واستشر مختص عند الحاجة.

## هيكل المشروع
```
trading_analyst_bot/
├── config.py                  # الإعدادات العامة (المستبعدات، أسلوب التداول)
├── data/
│   └── halal_watchlist.py     # قائمة الأسهم المسموحة (عدّلها بقائمتك الفعلية)
├── fetchers/
│   └── price_fetcher.py       # سحب بيانات الأسعار
├── analysis/
│   └── technical.py           # حساب المؤشرات الفنية
├── signals/
│   └── signal_generator.py    # بناء بطاقة القرار
└── main.py                    # نقطة التشغيل
```

## التشغيل
```bash
pip install -r requirements.txt
python main.py
```

## خطوتك الأولى
افتح `data/halal_watchlist.py` وحط رموز الأسهم الفعلية اللي تتابعها عند بوبيان كابيتال (لاحظ: رموز بورصة الكويت في yfinance قد ما تكون مدعومة بالكامل — إذا ما رجعت بيانات لسهم معين، هذي نقطة نحلها في المرحلة الجاية ببحث عن مصدر بيانات بديل).

## المرحلة ٢ — مستقبل تنبيهات تريدنق فيو ✅ (جاهزة)
```bash
python alerts/webhook_listener.py
```
يشتغل على `http://localhost:5000/tradingview-alert`. للربط الفعلي مع تريدنق فيو (لازم رابط عام على الإنترنت، مو localhost):
1. نزّل [ngrok](https://ngrok.com) وسوّي حساب مجاني.
2. شغّل: `ngrok http 5000`
3. بيعطيك رابط مثل `https://xxxx.ngrok-free.app` — هذا اللي تحطه في خانة Webhook URL داخل Alert في تريدنق فيو (وتضيف له `/tradingview-alert` في الآخر).
4. أي تنبيه يوصل يتخزن تلقائياً في `data/tradingview_alerts.json`.

⚠️ ملاحظة: ngrok المجاني يعطيك رابط مؤقت يتغير كل مرة تشغّله. للاستخدام الدائم تحتاج سيرفر صغير دائم الاتصال (أو خطة ngrok مدفوعة).
